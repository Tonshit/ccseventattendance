System Overview

v4.0.0

CCS Event Management System

An integrated offline-ready organizer platform designed for the College of Computer Studies. It manages event check-ins, real-time attendance tracking, student rosters, and PDF reports.

LocalStorage Authentication

Admin sessions and registered accounts are safely maintained in browser storage (ccs_admin_users & ccs_admin_current_user), allowing full functionality without requiring an external database.

Security & Protocols

Active Controls

Dynamic Attendance Code & QR

The 1-minute rotating cryptographic code and corresponding QR token prevent unauthorized check-in sharing or expired screenshots.

24-Hour Export Expiration

In accordance with data hygiene standards, attendance records for exported PDF reports are scheduled for automatic cleanup after 24 hours.
